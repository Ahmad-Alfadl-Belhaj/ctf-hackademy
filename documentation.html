📄 Documentation — regarder derrière le rideau

Cette page contient un secret… mais il n'est pas visible à l'écran. Suis le guide.

F12 / Inspecter — c'est quoi ?

Chaque page web est écrite en HTML. Ton navigateur te montre le résultat, mais tu peux voir les coulisses : le code qui a servi à la construire.

🧠 Analogie : une page web, c'est un tour de magie. Ce que tu vois, c'est l'illusion. Appuyer sur F12 (ou clic droit → Afficher le code source), c'est passer derrière la scène pour voir comment le tour est fait. Et les développeurs y laissent parfois traîner des notes oubliées.

À faire maintenant ⚙️

  1. Appuie sur F12 — ou clic droit n'importe où sur la page → « Afficher le code source de la page » (ou Inspecter).
  2. Cherche une ligne qui commence par <!-- tout en haut du code : c'est un commentaire, invisible sur la page.
  3. Tu y trouveras un flag HKM{...} et la prochaine consigne.

Astuce 📱 sur téléphone

Pas de touche F12 ? Ajoute view-source: devant l'adresse de la page dans la barre d'adresse, par exemple view-source:…/documentation.html, puis valide. Le code source s'affiche.

👀 Le flag HKM{...} ET la consigne pour la suite sont cachés dans le code source de cette page — invisibles ici. À toi de jouer : ouvre le rideau avec F12 (ou clic droit → Afficher le code source).
